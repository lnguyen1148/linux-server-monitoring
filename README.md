# Linux Server Monitoring & Automation

A hands-on Linux administration project demonstrating Bash scripting, system monitoring, automation, AWS CLI, Amazon S3, and technical documentation.

---

## Project Goal

Build a resusable Linux server monitoring solution that collects system health information, generats monitoring reports, and archives reports securely in Amazon S3 using AWS IAM roles.

> This project focuses on operating and monitoring Linux systems rather than deploying applications.
